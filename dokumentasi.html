Mau Jadi Developer?

AMOGENZ terbuka untuk developer yang mau berkarya bareng. Alurnya:

1. Minat

Hubungi via Instagram @ammogenz — perkenalkan diri dan kemampuanmu.

2. Seleksi

Founder menilai dan memutuskan. Kepercayaan adalah kunci.

3. Kesepakatan

Jaga kerahasiaan, patuhi Audit Bumerang, setiap kontribusi tercatat.

4. Akses

Diundang ke organisasi GitHub amogenz sebagai kolaborator repo privat.

5. Onboarding

Baca Indeks → README → ARCHITECTURE → CHANGELOG, lalu kerjakan satu tugas kecil dengan pendampingan.

Komunitas anak muda yang berkarya lewat ilmu, kreativitas, dan teknologi.
